# Musa:
MUSA es una aplicación desarrollada en Python con Tkinter para ayudar a creadores de contenido a organizar proyectos de marcas.

Funciones:
- Registrar proyectos
- Asignar prioridad
- Asignar dificultad
- Calcular precio sugerido
- Gestionar estados de trabajo
- Visualizar ingresos obtenidos
- Consultar proyectos completados

Tecnologías:
- Python
- Tkinter

Estructuras utilizadas:
- Listas
- Diccionarios
- Funciones
- Condicionales
- Ciclos for
